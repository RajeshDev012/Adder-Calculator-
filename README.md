# PySide6 Calculator

A simple desktop calculator built using **Python and PySide6**.

## Features

- Addition, subtraction, multiplication and division
- Decimal number support
- Clear button
- Rounded application corners
- Custom title bar
- Minimize and close buttons
- Button hover effects

## Technologies Used

- Python
- PySide6
- Qt Widgets

## Installation

1. Clone the repository:

```bash
git clone https://github.com/RajeshDev012/Adder-Calculator-.git
```

2. Navigate to the project folder:

```bash
cd PySide6-Calculator
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python main.py
```
